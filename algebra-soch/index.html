Алгебра, 7 класс: готовимся к СОЧ

Все 38 типов заданий из подготовки, по три уровня: A — базовый, B — средний, C — повышенный. У каждого типа сначала короткое правило, потом задания с разбором.

1. Прочитай правилоОно в синей рамке над заданиями.
2. Реши в тетрадиСначала сам. Застрял — нажми «Подсказка».
3. Проверь по шагамОткрывай решение по одному шагу и сравнивай со своим.
4. Отметь «Решил сам»Только если получилось без подсказки. Прогресс сверху.

Три ошибки, которые чаще всего делают

  • −34 = −81, а (−3)4 = 81. Без скобок минус в степень не входит.
  • Отрицательная степень даёт дробь, а не отрицательное число: 2−3 = 18.
  • Минус перед скобкой меняет знаки у всех членов в скобке.
