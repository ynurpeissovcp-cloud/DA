1.1 Нелинейные уравнения и системы

Линейное и нелинейное

Linear equation in two variables — первой степени, график прямая: 3x + 2y = 10.

Nonlinear — график не прямая: 5x² + 3y = 12, x² + y² = 25.

Решение — ordered pair (x, y). Проверка: подставь и посмотри, верно ли. (2, 1) для y = 3x − 5: 1 = 6 − 5 ✓.

Степень уравнения · degree

Степень члена = сумма степеней x и y. Степень уравнения = наибольшая из них

x²y² − y = 12 → 4.   x⁴y⁵ + 8x³y² = 18 → 9.   4x² − 7xy = 9 → 2.

Окружность · circle

Центр O(a, b), радиус R: (x − a)² + (y − b)² = R²

O(5, −3), R = 6 → (x − 5)² + (y + 3)² = 36.

Ловушки: знаки в скобках меняются на противоположные, а справа R в квадрате: R = 2.5 → 6.25, R = √11 → 11.

Точка лежит на графике

Подставь координаты точки вместо x и y, найди параметр.

S(2, 4) на nx² = 8 + 3y: 4n = 8 + 12 → n = 5.

Метод подстановки · substitution

  1. Из линейного уравнения вырази y (или x).
  2. Подставь во второе, реши квадратное уравнение.
  3. Найди вторую переменную для каждого корня.
  4. Проверь пары в обоих уравнениях.

x + y = 6, x² + 3y = 22 → y = 6 − x → x² − 3x − 4 = 0 → (−1, 7) и (4, 2).

Метод сложения · elimination

Умножь уравнение так, чтобы одна переменная (или y², xy) пропала при сложении.

x² − y² = 20, x + y² = 10 → сложили: x² + x = 30 → x = 5 или −6.

Ловушка: если y² = отрицательное число — решений с этим x нет. Если y² = 4, то y = ±2, это две пары.

Текстовые задачи · word problems

1. Составь модель (систему). 2. Реши. 3. Отбрось лишнее: длины не бывают отрицательными.

  • Двузначное число: цифры x, y; число = 10x + y.
  • Прямоугольный треугольник: a² + b² = c², площадь = ab/2.
  • Прямоугольник: P = 2(a + b), S = ab.

1.2 Неравенства с двумя переменными

Граница · boundary line

> или < → пунктир (dashed). ≥ или ≤ → сплошная (solid)

Пунктир: точки на линии НЕ решения. Сплошная: решения.

Как построить

  1. Нарисуй границу: прямую y = ax + b или параболу y = ax² + bx + c.
  2. Возьми пробную точку (test point), обычно (0, 0), если она не на границе.
  3. Верно → закрась сторону с точкой. Неверно → другую сторону.

5x + 2y > 10: (0,0) → 0 > 10 неверно → закрашиваем сторону без начала координат, линия пунктир.

Парабола и окружность

Парабола делит плоскость на interior (внутри) и exterior (снаружи).

Вершина: h = −b/2a, k = y(h). a > 0 — ветви вверх.

x² + y² > 25 → снаружи окружности радиуса 5; x² + y² < 25 → внутри.

Полуплоскости и четверти

  • выше оси x: y > 0; ниже: y < 0
  • правее оси y: x > 0; левее: x < 0
  • I четверть: x > 0, y > 0; II: x < 0, y > 0; III: x < 0, y < 0; IV: x > 0, y < 0
  • xy > 0 → I и III; xy < 0 → II и IV
  • «at least 22» → ≥ 22; «at most 55» → ≤ 55

Системы неравенств

Решение системы — область, где закрашенные части перекрываются (overlap)

Строй каждое неравенство отдельно, потом ищи общую часть.

2.1 Основные правила и формулы

P или C — объяснение на пальцах

Есть трое друзей: Аня, Боря, Вася. Выбираем двоих.

Позвать двоих в кино

Аня+Боря, Аня+Вася, Боря+Вася → 3 варианта.

«Аня и Боря» — то же самое, что «Боря и Аня». Компания одна.

Это сочетание C

Выбрать капитана и зама

АБ, БА, АВ, ВА, БВ, ВБ → 6 вариантов.

«Аня капитан, Боря зам» ≠ «Боря капитан, Аня зам».

Это перестановка P

Один вопрос, который всё решает: если двое выбранных поменяются местами — что-то изменится?

  • Да, изменится → P. Места, роли, порядок: 1-2-3 место, капитан/зам, книги в ряд, число из цифр, пароль.
  • Нет → C. Важно только, кто попал: команда, группа, комитет, горсть шаров, рукопожатие.

Как считать без формул (8 участников, выбираем троих):

  • P: на 1-е место 8 человек, на 2-е 7, на 3-е 6 → 8 · 7 · 6 = 336.
  • C: то же 336, но каждую тройку мы посчитали 6 раз (АБВ, АВБ, БАВ, БВА, ВАБ, ВБА) → 336 : 6 = 56.
  • Можно повторять (кодовый замок): 10 · 10 · 10 · 10 = 10 000.

C всегда меньше P: в C выброшены повторы из-за порядка

Правило суммы · sum rule

«ИЛИ» → складываем: m + n

Нельзя сделать оба действия сразу, выбираем одно. 4 блюда в казахском ресторане или 3 в узбекском → 4 + 3 = 7.

Правило произведения · product rule

«И» → умножаем: m · n

Делаем оба действия по очереди. 2 юбки и 3 рубашки → 2 · 3 = 6 нарядов.

Двузначные числа из {1,2,3,4,5}: 5 · 5 = 25. Из {0,1,2,3,4,5}: первая цифра не 0 → 5 · 6 = 30.

Факториал · factorial

n! = n · (n − 1) · … · 2 · 1,   0! = 1

3! = 6, 4! = 24, 5! = 120, 6! = 720, 7! = 5040, 8! = 40 320.

Сокращай: 6! / 3! = 6 · 5 · 4 = 120;   n! / (n − 1)! = n.

Ловушка: 5! + 2! ≠ 7!. Считай каждый отдельно: 120 + 2 = 122.

Перестановки · permutation

Порядок важен. P(n, n) = n!,   P(n, r) = n! / (n − r)!

4 книги в стопку: 4! = 24. Слово HUMANITY (8 разных букв): 8! = 40 320.

P(10, 4) = 10 · 9 · 8 · 7 = 5040 — просто перемножь r чисел, начиная с n вниз.

Обозначения: P(n, r) = ₙPᵣ = Pₙʳ.

Сочетания · combination

Порядок НЕ важен. C(n, r) = n! / ((n − r)! · r!)

Быстро: C(n, r) = P(n, r) / r!. Например C(10, 6): 10·9·8·7 / 4! = 210 (выгоднее брать меньшее: C(10,6) = C(10,4)).

C(n, 0) = C(n, n) = 1,   C(n, 1) = n,   C(n, 2) = n(n − 1) / 2.

Обозначения: C(n, r) = ₙCᵣ = (ⁿᵣ), читается «n choose r».

Как отличить P от C

Спроси себя: если поменять местами двух выбранных, получится что-то новое?

  • Да → P: места 1-2-3, президент/вице/секретарь, пароль, расстановка на полке, число из цифр.
  • Нет → C: команда, группа, комитет, набор шаров, рукопожатия, прямые через точки.

Замок с «кодом» — это НЕ сочетание: порядок цифр важен.

2.2 Как решать задачи

3 шага из учебника

  1. Порядок важен? → permutation (P) или combination (C).
  2. Найди n (из скольких) и r (сколько берём).
  3. Подставь в формулу. Несколько независимых выборов → умножаем. Несколько случаев («at least») → складываем.

С повторениями · with repetition

Повторять можно → nʳ. Нельзя → P(n, r)

Код из 4 цифр: 10⁴ = 10 000. Тест 9 вопросов true/false: 2⁹ = 512, а если можно пропустить: 3⁹.

Телефон из 7 цифр, первая не 0 и не 1, вторая 5, третья 3 или 4: 8 · 1 · 2 · 10⁴.

Выбор из двух групп

Выбрать 3 из 4 мальчиков И 4 из 6 девочек: C(4,3) · C(6,4) = 4 · 15 = 60

Каждую группу считаем отдельно, потом перемножаем.

«At least» · хотя бы

Разбей на случаи и сложи. 13 лампочек, 5 бракованных, берём 4, хотя бы 2 бракованные:

C(5,2)C(8,2) + C(5,3)C(8,1) + C(5,4)C(8,0) = 280 + 80 + 5 = 365.

Или через дополнение: все − ни одного. «Хотя бы 1 чёрный из 3 шаров» = C(9,3) − C(6,3).

«Не разделять» · склеиваем

Книги одного предмета стоят вместе: каждую группу — в один «блок».

(число блоков)! · (перестановки внутри каждого блока)

1 математика + 3 истории: 2! · 1! · 3! = 12. Гласные слова LEADING вместе: блок EAI + L, D, N, G → 5! · 3! = 720.

Буквы с повторами

Если буквы повторяются, делим на факториалы повторов.

DAD: 3! / 2! = 3.   CANADA (3 буквы A): 6! / 3! = 120.

Геометрия и рукопожатия

Рукопожатия n людей = прямые через n точек = C(n, 2).

Четырёхугольники из вершин 8-угольника: C(8, 4) = 70.

Обратная задача: 28 рукопожатий → n(n − 1)/2 = 28 → n = 8.

2.3 Треугольник Паскаля

Треугольник Паскаля — объяснение на пальцах

Как построить. Это пирамида из чисел. По краям всегда единицы. Каждое число внутри = сумма двух чисел над ним.

СтрокаЧислаСумма
011
11   12
21   2   14
31   3   3   18
41   4   6   4   116
51   5   10   10   5   132
61   6   15   20   15   6   164
71   7   21   35   35   21   7   1128

Пример: в строке 4 число 6 = 3 + 3 (два числа над ним из строки 3). В строке 5 число 10 = 4 + 6.

Важно: считаем строки с нуля. Верхняя «1» — это строка 0. Номер строки = второе число в ней (строка 5 начинается «1, 5, …»).

Зачем он нужен

Чтобы раскрывать скобки вида (a + b)ⁿ без долгого перемножения. Числа строки n — это коэффициенты.

(a + b)² = 1a² + 2ab + 1b² → строка 2: 1 2 1

(a + b)³ = 1a³ + 3a²b + 3ab² + 1b³ → строка 3: 1 3 3 1

Рецепт раскрытия (a + b)ⁿ

  1. Выпиши строку n — это числа-коэффициенты.
  2. Степень a идёт вниз: n, n−1, …, 0.
  3. Степень b идёт вверх: 0, 1, …, n.
  4. Перемножь в каждом столбике.

(a + b)⁴ = a⁴ + 4a³b + 6a²b² + 4ab³ + b⁴

В каждом члене сумма степеней = n (здесь 4).

Если внутри числа или минус

(x + 2)³: строка 3 = 1 3 3 1, вместо b подставляем 2:

1·x³ + 3·x²·2 + 3·x·2² + 1·2³ = x³ + 6x² + 12x + 8

Минус → знаки чередуются: (a − b)³ = a³ − 3a²b + 3ab² − b³.

Ловушка: степень берётся от всего числа в скобках: (−3y)² = 9y², (2x)³ = 8x³.

Три быстрых трюка

  • Сколько членов? На один больше степени: n + 1. (4x − 5)¹³ → 14.
  • Сумма коэффициентов? Подставь 1 вместо всех букв. (8a − 6b)⁹ → (8 − 6)⁹ = 512.
  • Свободный член (число без буквы)? Подставь 0 вместо буквы. (6m − 3)⁶ → (−3)⁶ = 729.
  • Сумма чисел в строке n = 2ⁿ.
