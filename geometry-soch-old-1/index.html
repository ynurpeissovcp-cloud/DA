1. Шпаргалка

1.1 · Основные понятия
Точка, прямая, плоскость point, line, plane
Неопределяемые понятия. Точка не имеет размера. Прямая бесконечна в обе стороны. Плоскость плоская, без толщины, бесконечна.
Отрезок line segment
Часть прямой с двумя концами. Имеет длину.
Луч ray
Часть прямой с одним концом, идёт бесконечно в одну сторону. Луч AB начинается в A.
Коллинеарные точки collinear
Лежат на одной прямой. Компланарные coplanar лежат в одной плоскости.
Полуплоскость half plane
Прямая делит плоскость на две полуплоскости. Сама прямая ни в одну не входит.
Угол angle
Два луча из одной точки (вершины, vertex). Обозначение ∠ABC: вершина всегда в середине.
Параллельные прямые parallel, ∥
Лежат в одной плоскости и не пересекаются.
Аксиома axiom / postulate принимается без доказательства. Теорема theorem доказывается.
Аксиомы, которые спрашивают чаще всего
Через две точки
проходит ровно одна прямая.
Из трёх точек на прямой
только одна лежит между двумя другими.
Две пересекающиеся прямые
имеют ровно одну общую точку.
Длина отрезка
всегда больше нуля. Если B между A и C:
AB + BC = AC
Мера угла
от 0° до 180°. Если луч OB внутри ∠AOC:
∠AOB + ∠BOC = ∠AOC
Параллельность
через точку вне прямой проходит только одна прямая, параллельная данной.
1.2 · Равные фигуры
Равные (конгруэнтные) фигуры congruent, ≅
Одинаковая форма и размер. Совпадают при наложении (сдвиг, поворот, отражение).
ΔABC ≅ ΔKMN
Порядок букв важен: A↔K, B↔M, C↔N. Значит AB = KM, BC = MN, AC = KN, ∠A = ∠K, ∠B = ∠M, ∠C = ∠N. Периметры тоже равны.
1.3 · Доказательства
Условное утверждение if–then
После «если» стоит условие hypothesis, после «то» стоит заключение conclusion.
Прямое доказательство direct proof
Цепочка шагов от данных к выводу, у каждого шага есть причина.
От противного proof by contradiction
1) Предположить обратное. 2) Получить противоречие. 3) Значит, утверждение верно.
1.4 · Смежные и вертикальные углы
Смежные linear pair
∠1 + ∠2 = 180°
Смежные дополнительные complementary
∠1 + ∠2 = 90°
Вертикальные vertical
∠1 = ∠3, ∠2 = ∠4
Запомнить: complementary = 90° (раньше в алфавите, меньше число), supplementary = 180°. Все 4 угла при пересечении двух прямых дают 360°. Перпендикулярные прямые ⊥ пересекаются под 90°.

2. Как решать: 6 рецептов

Почти любая задача СОЧ: найти, что чему равно, составить уравнение, решить его, подставить x обратно.

А. Отрезки на прямой

B между A и C → пишем AB + BC = AC и подставляем выражения.

AB=4x−2, BC=3x+1, AC=20 (4x−2)+(3x+1)=20 → 7x=21 → x=3

Б. Середина отрезка midpoint

M середина KL → две половинки равны: KM = ML, а весь отрезок KL = 2·KM.

KM=8a−6, ML=3(2a−1)+5 = 6a+2 8a−6 = 6a+2 → a=4, KL = 2·26 = 52

В. Смежные / дополнительные углы

Смежные: сумма 180°. Дополнительные: сумма 90°. Если дано отношение 1 : 5, углы равны x и 5x.

Отношение 1:5, сумма 90° → x+5x=90 → x=15° Углы: 15° и 75°

Г. Вертикальные углы

Вертикальные равны → приравниваем выражения. Соседний угол = 180° − найденный.

50° = 2x−10° → x=30°

«Сумма двух углов при пересечении прямых = 270°». Два смежных дают только 180°, значит это вертикальные: каждый 135°, а два других по 45°.

Д. Равные треугольники

Выписать пары по порядку букв, затем подставить числа.

ΔABC ≅ ΔEFD: AB=EF, BC=FD, AC=ED

Е. Виды треугольников с x

Равнобедренный: приравнять две стороны (проверить все три пары). Равносторонний: все три равны. Последовательные числа: n, n+1, n+2; чётные: n, n+2, n+4.

Стороны — последовательные числа, P=24: n+(n+1)+(n+2)=24 → 3n=21 → 7, 8, 9

Задание 1теория

Верно или неверно? a) Аксиому нужно доказывать. b) Через две точки проходит ровно одна прямая. c) У луча два конца.

Ответ

a) неверно, аксиома без доказательства; b) верно (это аксиома); c) неверно, у луча один конец.

Задание 2рецепт А

A, B, C лежат на одной прямой, B между A и C. AB = 2x + 3, BC = x + 6, AC = 24. Найдите x, AB и BC.

Ответ
2x+3 + x+6 = 24 → 3x = 15 → x = 5

AB = 13, BC = 11.

Задание 3рецепт Б

M — середина отрезка KL. KM = 3a + 4, ML = 5a − 6. Найдите a и длину KL.

Ответ
3a+4 = 5a−6 → 2a = 10 → a = 5

KM = 19, KL = 38.

Задание 4рецепт В

∠1 и ∠2 смежные. ∠1 = 3x + 20°, ∠2 = 2x + 10°. Найдите оба угла.

Ответ
5x + 30 = 180 → x = 30

∠1 = 110°, ∠2 = 70°.

Задание 5рецепт В

Отношение двух смежных дополнительных углов (complementary) 2 : 3. Найдите углы.

Ответ
2x + 3x = 90 → x = 18

36° и 54°.

Задание 6рецепт Г

При пересечении двух прямых вертикальные углы равны 4x − 10° и 2x + 30°. Найдите x и все четыре угла.

Ответ
4x−10 = 2x+30 → x = 20

Углы: 70°, 110°, 70°, 110°.

Задание 7рецепт Г

Сумма двух углов, образованных при пересечении двух прямых, равна 220°. Найдите все углы.

Ответ

220° больше 180°, значит углы вертикальные: по 110°. Два других: 180° − 110° = 70°.

Задание 8угол и его дополнение

Угол на 30° меньше, чем удвоенный дополнительный к нему угол (complement). Найдите оба угла.

Ответ
x = 2(90 − x) − 30 → 3x = 150 → x = 50

50° и 40°.

Задание 9рецепт Д

ΔABC ≅ ΔKMN. AB = 7 см, BC = 9 см, периметр ΔABC = 25 см. Найдите KN. Какой угол равен ∠M?

Ответ

KN = AC = 25 − 7 − 9 = 9 см. ∠M = ∠B (B на втором месте, M на втором месте).

Задание 10рецепт Е

Стороны треугольника: 2x + 3, x + 8 и 4x − 3. Первые две равны. Найдите стороны, периметр и вид треугольника по сторонам.

Ответ
2x+3 = x+8 → x = 5

Стороны 13, 13, 17. P = 43. Равнобедренный.

Задание 11классификация

Углы треугольника 30°, 50°, 100°. Какой он по углам? А треугольник с углами 45°, 45°, 90°?

Ответ

Первый тупоугольный (100° > 90°). Второй прямоугольный и равнобедренный.

Задание 12доказательство

a) Выделите условие и заключение: «Если угол прямой, то он равен 90°».
b) A, B, C на одной прямой, AB = 6 см, AC = 4 см, BC = 11 см. Докажите методом от противного, что C не лежит между A и B.

Ответ

a) Условие: угол прямой. Заключение: он равен 90°.

b) 1) Предположим, C лежит между A и B. 2) Тогда AC + CB = AB, то есть 4 + 11 = 15, а AB = 6. 3) 15 ≠ 6, противоречие. Значит, C не лежит между A и B.

Если ошибка в задании: найти похожий рецепт в разделе 2, перерешать, потом сделать похожую задачу из учебника (раздел Problems после каждой темы).
