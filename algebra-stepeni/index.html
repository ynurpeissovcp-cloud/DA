§1Что такое степень

an = a · a · … · a  (n раз)

  • a — основание base, n — показатель exponent
  • 26 = 64, 1100 = 1, 171 = 17
  • Минус в основании: чётная степень даёт «+», нечётная «−»: (−2)5 = −32

смотри на скобки. (−2)4 = 16, но −24 = −16: без скобок в степень идёт только 2.

§2Пять свойств степеней

am · an = am+nумножение → показатели складываем
aman = am−nделение → вычитаем
(am)n = am·nстепень степени → умножаем
(ab)n = anbnкаждый множитель в степень
(ab)n = anbnи числитель, и знаменатель

Пример: (−2b2)4 = 16b8, (3a)3·(2a8)2 = 27a3·4a16 = 108a19

свойства работают только при одинаковом основании: 42·23 = 85. И (a+b)2 = a2+b2 неверно.

§3Один приём, который решает половину СОЧ

Приведи всё к одному основанию, потом пользуйся §2.

4 = 22, 8 = 23, 16 = 24, 32 = 25, 64 = 26
9 = 32, 27 = 33, 81 = 34, 243 = 35
25 = 52, 125 = 53, 1000 = 103

Пример: 24 · 4383 = 24 · 2629 = 21 = 2

Сравнение: 2600 = 8200, 3400 = 9200, значит 3400 больше.

§4Ноль и минус в показателе

  • a0 = 1 (a ≠ 0);  00 не определено
  • a−n = 1an   2−3 = 18
  • (ab)−n = (ba)n   (32)−3 = 827
  • −70 = −1, но (−7)0 = 1; 5a0 = 5

Excluded value (какое x нельзя): основание степени 0 или минус-степени не может быть нулём. (2a − 6)0 → 2a − 6 ≠ 0 → a ≠ 3. (x + 2)−1 → x ≠ −2.

минус в показателе не делает число отрицательным: 2−3 = −8.

§5Последняя цифра степени

Смотрим только на последнюю цифру основания. Цикл повторяется:

цифрациклцифрацикл
22, 4, 8, 677, 9, 3, 1
33, 9, 7, 188, 4, 2, 6
44, 699, 1
0, 1, 5, 6 всегда остаются собой

Делим показатель на длину цикла (4 или 2). Остаток 1 → 1-я цифра цикла, 2 → 2-я, 3 → 3-я, остаток 0 → последняя.
72023: 2023 : 4 = 505, ост. 3 → третья цифра цикла 7, 9, 3, 1 → ответ 3.

§6Площадь, объём, последовательности

  • Сторону квадрата увеличили в k раз → площадь в k2 раз
  • Ребро куба в k раз → объём в k3 раз (ребро ×3 → объём ×27)
  • Объём ×64 → ребро ×4, потому что 43 = 64

Sequence: каждый раз умножают на одно число. 2, 6, 18, 54, … → ×3 → следующие 162, 486, 1458. Правило: 2 · 3n−1. Бактерии удваиваются каждый час: через 8 ч из 1 клетки 28 = 256.

§7Стандартный вид числа

a · 10n,  1 ≤ |a| < 10

  • Ставим запятую после первой ненулевой цифры, считаем, на сколько знаков сдвинули
  • Число большое (≥ 10) → n положительный: 780 000 000 = 7.8·108
  • Число меньше 1 → n отрицательный: 0.0000547 = 5.47·10−5
  • Обратно: 4.3·10−4 = 0.00043 (запятую влево на 4)

в учебнике scientific notation = наш «стандартный вид», а standard form = обычная запись числа (50 600). Не перепутай задание. И 82.5·106 не стандартный вид: 82.5 больше 10.

§8Действия в стандартном виде

  • × числа перемножаем, показатели складываем: (4.5·107)(5.1·104) = 22.95·1011 = 2.295·1012
  • ÷ делим, показатели вычитаем: 0.8·10−34·10−7 = 0.2·104 = 2·103
  • + − сначала одинаковые степени 10: 3.7·104 + 8.5·103 = 3.7·104 + 0.85·104 = 4.55·104
  • Сравнение: сначала показатели, при равных показателях числа. 8.4·107 < 2.3·109

Приставки: k = 103, M = 106, G = 109, c = 10−2, m = 10−3, μ = 10−6, n = 10−9. Пример: 15.48 km = 15.48·105 cm = 1.548·106 cm.

в конце всегда проверь, что первое число от 1 до 10. Если нет, сдвинь: 24·103 = 2.4·104.

§9Округление и погрешности

  • Цифра справа ≥ 5 → вверх, < 5 → вниз: 6.847 ≈ 6.85, 682 ≈ 680
  • Абсолютная absolute error: Δ = |a − ã|, a — точное, ã — приближённое
  • Относительная relative error: ε = |a − ã|ã · 100%
  • Запись a = ã ± Δ значит ã − Δ ≤ a ≤ ã + Δ: 52.24 ± 0.16 → 52.08 ≤ b ≤ 52.40
  • 420 g ± 3%: Δ = 3% от 420 = 12.6 g → 407.4 ≤ m ≤ 432.6

Пример: 128.0478 ≈ 128.05, Δ = |128.0478 − 128.05| = 0.0022.

36.97 до десятых — это 37.0, а не «37»: ноль после запятой показывает точность.

Пробный СОЧ, 40 минут

Задания в формате Summative Test из учебника (стр. 68–71). Реши всё на листке без подсказок, потом открывай «Ответ и решение» и проверяй. Задания A — база, B — средние, C — на высший балл.

1Evaluate · ВычислиA

a) (−3)4b) −34c) 50 + 2−3
Ответ и решение

a) (−3)4 = (−3)(−3)(−3)(−3) = 81: чётная степень, знак «+».

b) −34 = −(3·3·3·3) = −81: скобок нет, в степень идёт только 3.

c) 1 + 18 = 118

2Simplify · УпростиA

a) x5 · x7b) a10 : a4c) (y3)4d) (−2m3)5
Ответ и решение

a) x5+7 = x12   b) a10−4 = a6   c) y3·4 = y12

d) (−2)5 · (m3)5 = −32m15

3Write in scientific notation · Запиши в стандартном видеA

a) 0.000052b) 340 000 000c) 6.07·10−3 в standard form
Ответ и решение

a) запятую вправо на 5 знаков → 5.2·10−5

b) запятую влево на 8 знаков → 3.4·108

c) запятую влево на 3 → 0.00607

4Find the excluded value · Какое значение нельзяA

a) (2x − 8)0b) (x + 5)−1
Ответ и решение

a) 2x − 8 ≠ 0 → x ≠ 4   b) x + 5 ≠ 0 → x ≠ −5

00 не определено, а 0−1 = 1/0, на ноль делить нельзя.

5Calculate · ВычислиB

a) 25 · 4384b) 81−1 · 272
Ответ и решение

a) 25 · 26212 = 211−12 = 2−1 = 12

b) 3−4 · 36 = 32 = 9

6Simplify, no negative exponents · Упрости, без отрицательных показателейB

a) (3a2)3 · a−49ab) (2x−3y2)−2
Ответ и решение

a) 27a6 · a−49a = 3a6−4−1 = 3a

b) 2−2 · x6 · y−4 = x64y4

7Last digit · Найди последнюю цифруB

a) 72023b) 325 + 425
Ответ и решение

a) цикл 7, 9, 3, 1; 2023 : 4 = 505 ост. 3 → 3

b) 325: 25 : 4 ост. 1 → 3. 425: нечётная степень → 4. Сумма оканчивается на 3 + 4 = 7

a) (6·105)(4·10−2)b) 3.6·1051.2·109c) 4.5·106 + 7.8·105
Ответ и решение

a) 24·103 = 2.4·104

b) 3·105−9 = 3·10−4

c) 4.5·106 + 0.78·106 = 5.28·106

9Ascending order · Расставь по возрастаниюB

3.15·10−3,  0.0031,  3.2·10−4
Ответ и решение

0.0031 = 3.1·10−3. Самый маленький показатель −4.

3.2·10−4 < 0.0031 < 3.15·10−3

10Errors · ПогрешностиB

a) Округли 47.386 до десятых, найди абсолютную и относительную погрешность.
b) На упаковке написано 500 g ± 2%. В каких пределах масса?

Ответ и решение

a) сотые 8 ≥ 5 → 47.4; Δ = |47.386 − 47.4| = 0.014; ε = 0.014 : 47.4 · 100% ≈ 0.03%

b) 2% от 500 = 10 g → 490 g ≤ m ≤ 510 g

11Word problems · ЗадачиB

a) Ребро куба увеличили в 3 раза. Во сколько раз увеличился объём?
b) Свет проходит 3·105 km за секунду. Сколько km он пройдёт за 8 минут? Ответ в стандартном виде.
c) 2, 6, 18, 54, … Запиши правило и следующие три члена.

Ответ и решение

a) 33 = 27 раз

b) 8 мин = 480 s = 4.8·102 s; 3·105 · 4.8·102 = 14.4·107 = 1.44·108 km

c) каждый раз ×3, правило 2·3n−1; дальше 162, 486, 1458
