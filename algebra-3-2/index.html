Шаг 1Что это вообще такое

Помнишь машину-функцию из темы 3.1? В неё кладут x, а выходит y.

Domain · D(f)Все x, которые можно положить в машину. По-русски: область определения.
Range · E(f)Все y, которые могут выйти из машины. По-русски: множество значений.

Запоминалка: D — что даём (x), E — что едет обратно (y).

Шаг 2Domain и range из пар

Пара (x; y): первое число — x, второе — y. Пример:

(2; 5)(−1; 3)(0; −2)(4; 3)
Синие (первые) числа по возрастанию: D = {−1, 0, 2, 4}
Зелёные (вторые) по возрастанию: E = {−2, 3, 5}
Одинаковые числа пишем один раз: тройка встречается дважды, а в E она одна.

С точками на графике то же самое: сначала выпиши координаты каждой точки (x; y), дальше как с парами.

Шаг 3Domain и range по графику

Представь, что на график светят фонариком. Сверху — тень падает на ось x, это domain. Сбоку — тень на оси y, это range.

Закрашенная точка на конце — граница, она входит, скобка [ ]. Стрелка значит, что график идёт бесконечно дальше: пишем ∞ и круглую скобку.

Шаг 4Domain по формуле

Спроси себя: есть ли x, который сломает машину? В 7 классе машину ломает только одно: деление на ноль.

f(x) = 2x² − 3x + 1 → деления на x нет → D = ℝ (все числа)
f(x) = (x + 1) / 7 → делим на 7, а не на 0 → D = ℝ
f(x) = 9 / (x − 4) → знаменатель x − 4 = 0 при x = 4 → x ≠ 4
f(x) = 5 / (2x + 6) → 2x + 6 = 0 → 2x = −6 → x = −3 → x ≠ −3
Алгоритм: есть x в знаменателе? Нет — ответ ℝ. Да — приравняй знаменатель к 0, реши, этот x выкидываем.

Шаг 5Range по формуле

Подумай: какие y могут получиться? Три случая, которые встречаются в домашке:

Прямая f(x) = 3x − 2: можно получить любое число → E = ℝ
С квадратом f(x) = x² + 4: x² не бывает меньше 0, значит x² + 4 не меньше 4 → E = [4; ∞)
Число делить на x f(x) = 6 / x: 6 делить на что угодно никогда не даст 0 → y ≠ 0

Как записывать ответ

ℝвсе числа
x ≠ 4все числа, кроме 4
[−2; ∞)от −2 и больше, −2 входит
(−∞; 4]от 4 и меньше, 4 входит
{−1, 0, 2}только эти числа (для пар и точек)

В учебнике пишут D(f) = … и E(f) = …. Вместо «;» иногда ставят «,»: [−2, ∞).
