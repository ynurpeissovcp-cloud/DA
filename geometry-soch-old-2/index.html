8 типов задач правило + пример

1. Сложение отрезков · Segment addition

B между A и C → AB + BC = AC

AB = 4x − 2, BC = 3x + 1, AC = 20.
(4x − 2) + (3x + 1) = 20 → 7x − 1 = 20 → x = 3

Если просят «найди AB», не забудь подставить x обратно: AB = 4·3 − 2 = 10.

2. Середина отрезка · Midpoint

M — середина KL → KM = ML, KL = 2·KM

KM = 8a − 6, ML = 3(2a − 1) + 5.
8a − 6 = 6a + 2 → 2a = 8 → a = 4

O — середина KL, OL = 7 см → KL = 14 см.

3. Смежные углы · Adjacent supplementary

∠1 + ∠2 = 180°

∠1 = 4x + 75°, ∠2 = 5x + 15°.
9x + 90 = 180 → x = 10 → ∠2 = 5·10 + 15 = 65°

Отношение 1 : 4 → 180 : 5 = 36 → углы 36° и 144°. Делим 180 на сумму частей.

4. Дополнение до 90° · Complementary

∠1 + ∠2 = 90°

Отношение 1 : 5.
x + 5x = 90 → x = 15 → углы 15° и 75°

Complement 28° = 90 − 28 = 62°. Supplement 108° = 180 − 108 = 72°.

5. Вертикальные углы · Vertical angles

напротив → равны; рядом → 180°

50° и 2x − 10° вертикальные.
2x − 10 = 50 → x = 30

Две прямые дают 4 угла: только два разных значения, и их сумма 180°. «Сумма двух углов 270°» → это вертикальные углы (смежные дали бы 180), каждый 135°, остальные два по 45°.

6. Равные треугольники · Congruent triangles

ΔABC ≅ ΔDEF: A↔D, B↔E, C↔F

Букву сопоставляем по месту в записи: 1-я с 1-й, 2-я со 2-й, 3-я с 3-й.
Стороны: AB = DE, BC = EF, AC = DF. Углы: ∠A = ∠D, ∠B = ∠E, ∠C = ∠F.

ΔPRS ≅ ΔKLM → ∠S = ∠M, SP = MK. Периметры равных фигур равны.

7. Аксиомы и доказательства · Axioms & proofs

If (условие), then (вывод)

«If two lines intersect, then their intersection is one point»: hypothesis — two lines intersect; conclusion — one point.

От противного (by contradiction): 1) предположи обратное; 2) получи противоречие; 3) значит, верно исходное.
AB = 7, AC = 2, BC = 10. Если C между A и B, то AB = AC + CB = 12, а AB = 7. Противоречие, значит C не между A и B.

8. Виды треугольников и периметр · Triangle types (2.1)

isosceles: 2 стороны равны · equilateral: 3 равны · P = a + b + c

Стороны 3x, x + 10, 6x − 15. При каком x треугольник equilateral?
3x = x + 10 → x = 5. Проверка: 15, 15, 6·5 − 15 = 15 ✓

Isosceles: legs 3x + 1 и 5x − 4, base 2x + 11. Найди периметр.
3x + 1 = 5x − 4 → x = 2.5 → стороны 8.5, 8.5, 16 → P = 33

По углам смотри на самый большой угол: больше 90° → obtuse, ровно 90° → right, все меньше 90° → acute. «Consecutive numbers» — подряд идущие: n, n + 1, n + 2.
