Алгебра 7 · тема 3.4 · The function y = mx + n

Линейная функция y = mx + n и домашка № 3, 5, 6

Пройди 5 коротких шагов, потом разминку. Домашку страница проверяет сама: таблицы, формулы и даже графики, которые ты строишь пальцем на сетке. Решение откроется только после трёх неудачных попыток.

Домашка:
0 из 3

Шаг 1Что такое y = mx + n

Такси: 500 тг за посадку и 100 тг за каждый километр. За x км заплатишь y = 100x + 500.

m = 100 — сколько добавляется за каждый шаг x (наклон прямой)
n = 500 — сколько есть сразу, когда x = 0 (где прямая пересекает ось y)
Это как y = mx из прошлой темы, только прямая сдвинута на n вверх или вниз. График — всегда прямая линия (straight line). Поэтому функция называется линейной (linear function).

Шаг 3Таблица значений (это № 3)

f(x) — это то же самое, что y. Чтобы заполнить таблицу, подставь каждый x в формулу.

f(x) = 2x − 1, x = −2 → y = 2 · (−2) − 1 = −4 − 1 = −5 → пара (−2; −5)
x = 0 → y = 2 · 0 − 1 = −1 → пара (0; −1)
x = 3 → y = 2 · 3 − 1 = 5 → пара (3; 5)

Отрицательный x всегда бери в скобки. В столбике (x, y) просто записываешь x и y вместе.

Шаг 4Как получить y = … из x + 2y = 3

Иногда формула записана не в виде y = …, а так: 2x + y = 5 или 3x + 6y = 12. Тогда сначала оставь y одного слева.

1. Перенеси слагаемое с x вправо и смени ему знак: 3x + 6y = 12 → 6y = 12 − 3x
2. Раздели каждое слагаемое на число перед y: y = 12 : 6 − 3x : 6 → y = 2 − 0,5x
Осторожно с минусом перед y: x − y = 1 → −y = 1 − x → умножь всё на −1 → y = x − 1

По-английски это называется function form — «в виде функции».

Шаг 5Как построить график (это № 5)

Прямую определяют две точки. Значит, достаточно найти две.

1. Приведи к виду y = mx + n.
2. Возьми x = 0: тогда y = n. Это первая точка, она на оси y.
3. Возьми ещё один удобный x, чтобы y получился целым. Например, для y = 2 − 0,5x бери x = 2 или x = 4.
4. Отметь обе точки и проведи через них прямую.

В тренажёре точку ставят касанием сетки. Тронь точку ещё раз — она исчезнет.
