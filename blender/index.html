Тренажёр Blender для Арсена

Информатика: добавить 2 разные фигуры, расставить их по осям X, Y, Z, сохранить файл и написать 3–4 предложения на английском.

Что нужно понять за 5 минут

Три оси — это три направления

X — краснаявправо / влево
Y — зелёнаявперёд / назад (вглубь)
Z — синяявверх / вниз. В Blender Z — это высота.

Позиция объекта записывается тремя числами: X, Y, Z. Например (2, 0, 1) — на 2 вправо, по глубине в центре, на 1 вверх.

Главные клавиши

Shift+AAdd — добавить фигуру (Mesh → Cube, UV Sphere, Cylinder, Cone, Torus…)
GGrab / Move — двигать объект
G Xдвигать только по оси X (так же G Y, G Z)
G Z 2 Enterсдвинуть ровно на 2 вверх
Nбоковая панель: вкладка Item → Location X, Y, Z — вписать точные числа
RRotate — повернуть (R Z 45 = на 45° вокруг Z)
SScale — изменить размер (S 2 = в 2 раза больше)
Alt+Gвернуть объект в центр (0, 0, 0)
X или Deleteудалить выделенный объект
Ctrl+Zотменить последнее действие
Ctrl+SSave — сохранить файл (.blend)
Esc / правая кнопкаотменить начатое движение

Как смотреть на сцену

Колёсико мышиприблизить / отдалить
Зажать колёсико и вестивращать вид вокруг сцены
Shift + зажать колёсикосдвинуть вид
Кружки X, Y, Z справа сверхуклик — вид точно спереди/сбоку/сверху (удобно на ноутбуке без цифровой клавиатуры)
Num 1 / Num 3 / Num 7вид спереди / справа / сверху
Частая ошибка: клавиши работают, только если мышка находится над окном с 3D-сценой. Если мышка над другой панелью — ничего не произойдёт.
Важно: G X 3 сдвигает на 3, а не в точку 3. Чтобы поставить объект точно в X = 3, проще открыть панель N и вписать 3 в поле Location X.

Домашнее задание по шагам

Ставь галочки по ходу работы. Галочки сохраняются в этом браузере.

  • Открой Blender. Нажми на любое место сцены, чтобы закрыть заставку. На сцене уже есть куб (Cube), камера и лампа.
  • Фигура 1 — куб уже есть. Кликни по нему левой кнопкой — появится оранжевая обводка, значит он выделен.
  • Поставь куб по осям. Нажми N, справа откроется панель. Вкладка Item → Location. Впиши: X = -2, Y = 0, Z = 1 (каждый раз Enter). Куб уедет влево и поднимется.
  • Добавь фигуру 2. Мышку над сценой → Shift+A → Mesh → UV Sphere (шар). Шар появится в центре.
  • Поставь шар по осям. В панели Location впиши: X = 2, Y = 1, Z = 1.
  • По желанию — фигура 3. Shift+A → Mesh → Cone (конус). Подвинь клавишами: G Y -3 Enter (на 3 назад по Y).
  • Проверь со всех сторон. Покрути вид колёсиком, нажми кружки X, Y, Z в правом верхнем углу. Фигуры не должны проваливаться друг в друга.
  • Сохрани. Ctrl+S → откроется окно выбора папки → внизу впиши имя, например Arsen_3D_project.blend → кнопка Save. Запомни папку!
  • Запиши свои числа. Какие фигуры и какие координаты X, Y, Z у каждой — пригодится для текста (вкладка 5).
  • Напиши 3–4 предложения на английском о том, какие инструменты использовал (вкладка 5).

Самопроверка прямо в Blender

Небольшой скрипт сам проверит работу: сколько фигур, разные ли они, где стоят и сохранён ли файл.

  1. Вверху Blender открой вкладку Scripting.
  2. В большом окне посередине нажми + New.
  3. Скопируй код ниже и вставь (Ctrl+V).
  4. Нажми кнопку ▶ (Run Script) или Alt+P — появится окошко с результатом.
  5. Вернись на вкладку Layout, чтобы продолжить работу.
import bpy

objs = [o for o in bpy.context.scene.objects if o.type == 'MESH']
names = {"Cube":"Куб","Sphere":"Шар","Icosphere":"Икосфера","Cylinder":"Цилиндр",
         "Cone":"Конус","Torus":"Тор","Plane":"Плоскость","Suzanne":"Обезьянка",
         "Circle":"Круг","Grid":"Сетка"}
lines = []
kinds = set()
places = set()
for o in objs:
    base = o.data.name.split('.')[0]
    kinds.add(base)
    x, y, z = o.location
    places.add((round(x, 2), round(y, 2), round(z, 2)))
    lines.append(f"{names.get(base, base)}:  X={x:.2f}   Y={y:.2f}   Z={z:.2f}")

def mark(ok):
    return "OK  " if ok else "НЕТ "

lines.append("")
lines.append(mark(len(objs) >= 2) + f"Фигур на сцене: {len(objs)} (нужно 2+)")
lines.append(mark(len(kinds) >= 2) + f"Разных видов фигур: {len(kinds)} (нужно 2+)")
lines.append(mark(len(places) == len(objs) and len(objs) > 0) + "Все фигуры стоят в разных местах")
saved = bool(bpy.data.filepath) and not bpy.data.is_dirty
lines.append(mark(saved) + ("Файл сохранён: " + bpy.path.basename(bpy.data.filepath)
                             if saved else "Файл не сохранён или есть изменения - нажми Ctrl+S"))

def draw(self, context):
    for t in lines:
        self.layout.label(text=t)

bpy.context.window_manager.popup_menu(draw, title="Проверка задания", icon='INFO')
print("\n".join(lines))
Если везде OK — домашнее задание в Blender выполнено. Останется только текст.
