Шаг 1Что такое intercept

Intercept (по-казахски қиылысу нүктесі) — это точка, где прямая пересекает ось.

x-interceptПрямая пересекает ось x. Там всегда y = 0. Точка (a; 0).
y-interceptПрямая пересекает ось y. Там всегда x = 0. Точка (0; b).
Запомни наоборот: ищешь пересечение с осью x — ставь y = 0. Ищешь с осью y — ставь x = 0.

Шаг 3Как найти без графика (пример из учебника)

Функция y = 2x + 4.

y-intercept: ставим x = 0 → y = 2 · 0 + 4 = 4 → точка (0; 4)
x-intercept: ставим y = 0 → 0 = 2x + 4 → 2x = −4 → x = −2 → точка (−2; 0)

Для y = mx + n y-intercept всегда равен n, его видно сразу.

Шаг 4Если уравнение вида 3x + 2y = 12

Переделывать в y = … не нужно. Просто «закрой пальцем» одну букву, то есть поставь вместо неё 0.

x = 0: 3 · 0 + 2y = 12 → 2y = 12 → y = 6 → (0; 6)
y = 0: 3x + 2 · 0 = 12 → 3x = 12 → x = 4 → (4; 0)

Ответ может быть дробным, например x = −2,5. Это нормально.

Шаг 5Как построить график (это № 5)

Прямую задают две точки, а два intercept — это как раз две точки. Отметь их и проведи через них прямую. Этот способ и называется intercept method.

Если точка не попадает на клеточку (например, −2,5) или уходит за край сетки, возьми любой другой удобный x и посчитай y.

Шаг 6Как узнать прямую по графику (№ 6) и проверить точку (№ 7)

№ 6. Смотри на два признака:

1. Где прямая пересекает ось y: это число n (у y = 3 − 5x это 3).
2. Куда она идёт: если m > 0, поднимается слева направо; если m < 0, опускается. Чем больше число m без знака, тем круче прямая.

№ 7. Пара (3; 1) значит x = 3, y = 1. Подставь оба числа в уравнение:

x + 2y = 5 → 3 + 2 · 1 = 5 → 5 = 5 → да, satisfies.
Если слева получилось другое число, то нет.
