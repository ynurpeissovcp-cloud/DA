Шаг 1Функция — это машина

В машину кладут число x. Машина делает с ним одно и то же действие — это правило. На выходе получается число, его пишут f(x) или y.

Запись f(3) читается «эф от трёх». Она значит: положи в машину 3 и посмотри, что выйдет.

кладём x
3
получаем3

Нажимай «+» и «−», меняй правило и смотри, что делает машина.

Главное: каждому x функция даёт ровно один ответ. Если одному x соответствуют два разных y, это не функция.

Шаг 3Четыре примера (не из домашки)

1. Слова → формула. «Square the number, then add 1».

square the number → x²
then add 1 → + 1
f(x) = x² + 1

2. Найти y по x. f(x) = 3x², найди f(−2).

Вместо x пишем (−2), обязательно в скобках:
f(−2) = 3·(−2)² = 3·4 = 12
Сначала степень, потом умножение. (−2)² = 4, минус исчезает.

3. Найти x по y. y = 12x, y = 4. Найди x.

12 : x = 4. Какое число подходит? Делим наоборот: x = 12 : 4 = 3
Проверка: 12 : 3 = 4 ✓

4. Найти x, если известен ответ функции. f(x) = 4x + 1, f(x) = 9.

Значит 4x + 1 = 9 — обычное уравнение
4x = 9 − 1 = 8
x = 8 : 4 = 2
Проверка: 4·2 + 1 = 9 ✓

Задачи такие же, как в домашке, только с другими числами. Реши их, и домашка пойдёт легко.
