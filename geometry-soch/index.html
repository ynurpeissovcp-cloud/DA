Геометрия, 7 класс: готовимся к СОЧ

Все 36 типов заданий из подготовки, по три уровня: A — базовый, B — средний, C — повышенный. У каждого типа сначала короткое правило, потом задания с разбором.

1. Прочитай правилоОно в синей рамке над заданиями.
2. Реши в тетрадиСначала сам. Застрял — нажми «Подсказка».
3. Проверь по шагамОткрывай решение по одному шагу и сравнивай со своим.
4. Отметь «Решил сам»Только если получилось без подсказки. Прогресс сверху.

Три ошибки, которые чаще всего делают

  • Смежные углы в сумме дают 180°, а вертикальные углы равны. Не путай!
  • «Дополнительные» углы в этой подготовке дают в сумме 90°, «смежные» — 180°.
  • В записи △ABC ≅ △DEF важен порядок букв: A ↔ D, B ↔ E, C ↔ F.
